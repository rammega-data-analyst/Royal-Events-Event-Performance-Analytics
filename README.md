# Royal Events – Event Performance Analytics

## Project Overview
This Power BI project analyzes event performance, bookings, revenue, expenses, and customer-related metrics to support data-driven business decisions.

## Project Objectives
- Analyze event performance and booking trends.
- Evaluate revenue and expenses.
- Understand event categories and customer patterns.
- Monitor key business performance indicators.
- Present insights through an interactive Power BI dashboard.
## Project Files
- `Royal_Events_Events_Raw.csv` – Raw event dataset.

## Tools & Technologies
- Microsoft Power BI
- SQL Server
- SQL


## Data Cleaning
- Created the database `RoyalEventsDB`.
- Cleaned and prepared the event dataset.
- Final cleaned table: `dbo.Royal_Events_Events_Final`.
- Final cleaned dataset contains 1,209 records.
